# VASIKO tasks

`tasks/` содержит рабочие задачи ВАСИКО. Это не продукты и не рабочие пространства.

- `records/` — локальные JSON-записи задач, создаваемые `core.task_manager.LocalTaskManager`.
- `task-index.md` — описание индекса и жизненного цикла.

Файлы данных из `records/` не коммитятся в GitHub. В текущем блоке `palmistry-pilot` не создаётся автоматически: это отдельная задача, которая появится в соответствующем блоке.
