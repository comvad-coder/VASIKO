# Approvals

В Block 9 нет выданных approvals.

План продвижения пока не утверждён, URL/ZIP продукта отсутствует, публикации и внешние действия запрещены. После получения входных данных approval должен ссылаться на конкретную draft strategy, каналы, бюджет `0` до отдельного решения и список разрешённых действий.
