# Palm promotion project model

- `project_id`: `palm-promotion`
- `name`: `Palm promotion pilot`
- `description`: группировка задачи продвижения Palm и связанных product/workspace references
- `task_ids`: [`palmistry-pilot`]
- `product_ids`: [`palm`]
- `workspace_ids`: [`palm-site`]
- `status`: `metadata_only`

Project не является задачей, продуктом или workspace и не выполняет действий самостоятельно.
