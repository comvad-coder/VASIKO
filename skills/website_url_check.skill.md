# Website URL Check Skill

## Назначение

Read-only проверка публичного URL продукта перед внутренним анализом ВАСИКО. Skill не изменяет сайт и не подключает AI.

## Вход

- полный `http://` или `https://` URL;
- изолированный workspace;
- необязательный `task_id`.

Локальные IP, localhost, URL с логином/паролем и приватные адреса запрещены.

## Выход

- `analysis/url-check-report.json`;
- `analysis/url-check-report.md`;
- HTTP status и final URL;
- content type и размер ответа;
- title, meta description, H1;
- ссылки;
- базовые технические сигналы.

## Границы

Skill использует только read-only HTTP GET с ограничением времени и размера ответа. Он не использует credentials, AI, реальные внешние API, публикации, платежи, рассылки или изменения сайта.

## Следующий шаг

Отчёт передаётся внутреннему product-analysis/promotion контуру только после проверки результата пользователем. Автоматические внешние действия запрещены.
