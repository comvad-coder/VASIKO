# Promotion plan contract

## Input

`PromotionBrief` содержит `task_id`, `product_id`, название и URL продукта, описание, аудиторию, регионы, доступные assets, существующие каналы и ограничения.

## Output

`PromotionPlan` содержит оценки каналов, ровно две первичные рекомендации, фазы выполнения, статус `draft` или `awaiting_approval` и флаги внешнего исполнения.

## Safety

Block 8 не делает HTTP-запросы по URL, не вызывает реальные API, не публикует материалы, не отправляет сообщения, не читает credentials и не тратит бюджет. `execute()` намеренно возвращает ошибку stubbed. Внешнее действие возможно только после будущего approval/integration контура.
