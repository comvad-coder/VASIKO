# Module index

## Активные модули

На момент Block 5 активных модулей нет. Registry создаётся пустым и не выдаёт права автоматически.

## Зарезервированные модули следующих этапов

- `promotion_engine` — будущий модуль продвижения Palm.
- `project_workspace` — будущий модуль ZIP и изолированной рабочей копии.

## Future

Каталог `modules/future/` содержит только архитектурные места для будущих модулей. Эти каталоги не зарегистрированы, не протестированы и не имеют permissions.
