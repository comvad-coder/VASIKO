# project_workspace

Модуль Block 7 для безопасной загрузки ZIP и создания изолированной рабочей копии внешнего продукта. Runtime-код находится в `workspace_manager.py`.

Порядок import: проверка архива → сохранение оригинала → безопасная распаковка → определение стека → import report → backup перед будущими изменениями.

Модуль пока не зарегистрирован в Module Registry и не активирован для внешних задач. Реальные изменения продукта, публикации, API и URL import не выполняются.
