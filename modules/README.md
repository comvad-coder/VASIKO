# VASIKO modules

`modules/` содержит функциональные блоки ВАСИКО. Registry не смешивает модуль с задачей, продуктом, workspace, skill или агентом.

Регистрация хранит manifest в `modules/registry/*.json`. Пустой registry не означает, что модуль активен. Активация возможна только после успешных тестов и явного `approval_id`.

В текущем блоке реальные модули не запускаются. `promotion_engine` и `project_workspace` только зарезервированы под следующие этапы.
