# 07. Метрики и эксперименты

## Правило
Метрики выбираются от бизнес-цели назад. Не подменять продажи показами и охватом.

## Примеры дерева метрик
- Продажи: выручка, валовая прибыль, число заказов, конверсия, CAC, возвраты.
- Лиды: число квалифицированных лидов, стоимость лида, конверсия лида в продажу.
- Контент: удержание/досмотр, сохранения, переходы, целевые действия.
- Удержание: повторная покупка, отток, частота использования — если продукт позволяет измерить.

Использовать только метрики, для которых доступны надёжные данные. Расшифровывать определения.

## Интерпретация
- Сравнивать с базовым уровнем, если он есть.
- Учитывать сезонность, размер выборки и другие изменения.
- Не заявлять причинность по простому совпадению.
- При малом объёме данных писать «сигнал предварительный».
- Не обещать статистическую значимость без корректного расчёта.
- После теста фиксировать: результат, вывод, уверенность, следующий шаг.
