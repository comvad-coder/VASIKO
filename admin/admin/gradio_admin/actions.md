# Gradio Admin actions — Block 1

| Действие | Реализация | Внешний эффект |
|---|---|---|
| Create task | локальный `AdminStore` | отсутствует |
| View task/status | локальная таблица | отсутствует |
| Load URL | сохраняется в записи задачи | URL не запрашивается |
| Load ZIP | сохраняется только имя входного файла | архив не распаковывается |
| View plan | выводится stub-план | отсутствует |
| Approve | локальная запись approval | публикация не выполняется |
| Start/stop | смена статуса | workflow не запускается |
| Action log | локальный журнал | не отправляется наружу |
| Backup | JSON snapshot в `runtime/backups` | секреты не включаются |
| Diagnostics | локальные проверки заглушек | внешние сервисы не проверяются |
